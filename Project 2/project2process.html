The Process I Undertook In Planning and Designing the Website

The purpose of wireframes is to help users easily navigate through the website. Babich (2020b) states that “A wireframe is a static, low-fidelity representation of the different screens and pages that form a product. Wireframes use simple shapes to create visual representations of page layouts” (p. 1). In my five wireframes, I use the colours black and white to draw attention and use the colour contrast tools to create visual accents. Babich (2020b) states that “Use colour to draw attention. Wireframes traditionally use black and white or grayscale, but feel free to use a contrasting colour to create visual accents” (p. 5). For example, in the Home page of my website, I used black for the lines that will be replaced with words in my prototype or box lines for borders with a white background. This approach focuses on the structure, layout and user flow without getting distracted by the aesthetics. For all five of the wireframes used for my website, I added only essential elements such as layout, structure, navigation, content hierarchy, and functionality to establish the foundational structure for my prototype.

First, I applied the Gesalt principles, which states that "Gestalt principles explore users’ visual perception of objects in relation to each other, including similarity, continuity, proximity, symmetry, and closure. All of these can influence how designers should organize graphical information on the screen. A UX architect uses the principles to decide how to present and organize the information on a page" (Babich, 2020a). This makes my website easier to navigate, guides user attention. This enhances usability and navigation as principles provide a framework for organizing content logically, making it easier for visitors to find what they are looking for. For example, I used the principle Proximity to group items in my resume and home page to physically close together, so that the user can understand that a photo or title belong to the same project. I also used the Gesalt principles to create a clear visual hierarchy that direct users' attention to the most important elements. For example, I used the Ground principle for my contact information page to make the contacts stand out as a figure against a contrasting background.

Next, I followed the “Consistency and Standards” rule, stating that “Users should not have to wonder whether different words, situations, or actions mean the same thing. Follow platform and industry conventions” (Nielsen, 2024). For all 5 web pages, I ensured a predictable and inituitive user experience by maintaining in a uniformity in design and language. The visuals on the home page maintain a consistent colour scheme. All typography and spacing are consistent throughout the website with Times New Roman as the typography used for the whole website. The main navigation menu is located on the same place for all 5 web pages, which is on the top right of each of the 5 web pages. All established conventions are followed so that users are already familiar with from other websites and apps.

I also applied the rule of “Aesthetic and Minimalist Design”, which states that “Interfaces should not contain information that is irrelevant or rarely needed. Every extra unit of information in an interface competes with the relevant units of information and diminishes their relative visibility” (Nielsen, 2024). Based on this rule, I added text descriptions to my images, known as alt text, under each image. For example, the photos, videos and audios in the Photography section have alt text for enhancing the user experience by providing a functional, non-visual text alternative that upholds the design principle of clarity and purpose.

References to any relevant readings

The headings of each section of the website is known as structural navigation. This type of structural navigation is an example of Global navigation. Kalbach (2007) explains that “The global navigation generally represents the top-level pages of a site’s structure – or the pages just below the home page. The links to the main navigation are expected to lead to pages within the site and behave in a very consistent way” (p. 86-87). An example of the structural navigation is on the resume page section Hobbies. The Hobbies section is a top-level page that improves the site orientation due to its persistent nature.

The footer of each page of the website is known as associative navigation. It is part of contextual navigation, which links transitions to similar pages at the same level within the site. Kalbach (2007) notes that related links can be displayed, “contextual navigation may appear at the end or to the side of the content” (p. 92). On my website, the footers on each page group links together that do not fit into my personal website's main hierarchy structure. The footer on each page offers alternate pathways related to my website's overall content and purpose, instead of a single, primary user goal.

I have applied Brown's Information Architecture principle "The Principle of Exemplars" for my website, which states that the website should "describe the contents of categories by showing examples of the contents" (p. 32). For example, in my resume page, I provided examples in hobbies in the hobbies section that I have since when I was very young. Another example is in the Photography page, I provided examples of photos of places that I have been to to tell readers know why travelling is good for life.

I have also applied Brown's Information Architecture principle "The Principle of Multiple Classification", which states that the website should "offer users several different classification schemes to browse the site’s content" (p. 33). For example, I have a main menu which is the navigation bar that allows users to browse the content by the primary categories I defined: Process, Contact Information, Resume, Photography and Home. Another example is on the Contact Information page, I have a form that allows users with a specific goal in mind to jump directly to the relevant content by bypassing the main browsing hierarchy.

I have also applied Brown's Information Architecture principle "The Principle of Choices", which states that "the webaite should create pages that offer meaningful choices to users, keeping the range of choices available focused on a particular task." (p. 31). For example, in my navigation bar of each page, I have a few navigation links: "Home", "Photography", "Resume", "Contact Information" and "Process Document" that help users to immediately understand my personal website's primary sections and where to go for specific information without feeling overwhelmed.

Accessibility and Usability-Applying the POUR Framework

Perceivable

Guideline 1.3.2 Meaningful Sequence: When designing the layout of the contact information page, I made a size distinction between the sections "All of My Contacts" and "Contact Me". To avoid confusing the users, the accompanyed text descriptions use differentiated by text style.

Guideline 1.4 Distinguishable: A contrast tracker is used to make sure that it easier for users to see the content including separating foreground from background. The use of colour is not used as the only visual means of conveying information, indicating an action, prompting a response, or distinguishing a visual element. The screenshot below successfully passed the colour contrast for the foreground words with the background with WebAIM.

Guideline 1.4.6 Contrast (Enhanced): The contrast tracker from the screenshot above passes the 7:1 contrast ratio for the visual presentation of text and images of text for each of the 5 pages for my website.

Guideline 1.4.7 Low or No Background Audio: In the photography page, there is an audio that explains the classroom for my CCT260H5 Web Development and Design I class I have this semester. There is low background audio which the audio is 10 dB (decibels) lower than the foreground speech content, which is lower than the expected 20 decibils.

Operable

Guideline 2.1.1 Keyboard: In the Contact Information page, there is a form page Contact Me that requires keyboard input. All functionality of the content is operable through a keyboard interface without requiring specific timings for individual keystrokes.

Guideline 2.2.3 No Timing: Timing is not an essential part of this website presented by the website's content. All pages on my website do not use time limits, except for the video and audio that I used in the Photography page.

Guideline 2.4: Navigable: This website provides different ways to help users navigate and find content. The website is navigated sequentially, and the navigation sequences affect both meaning and operation for focus order. This allows focus the focusable components of the website receive focus in an order that preserves both meaning and operability.

Guideline 2.4.3 Focus Order: When designing the layout of the resume, I used focus order to allow users who have disabilities to access all interactive elements in a meaningful sequence.

Guideline 2.4.6 Headings and Labels: For each subsection, headings are labelled to organize content, improve readability, and enhance navigation by structuring documents into logical subsections. These headings break up large amounts of text into smaller, manageable sections, creating a clear hierarchy and logical flow of ideas.

Understandable

Guideline 3.1 Readable: This website uses a clear and inituative navigation with each page marked by a title and each section by a heading to inform viewers about the content. This website uses a structurally-hierarchy of headings and distinct formatting to maintain a unified style for all five web pages I have for this project.

Guideline 3.1.1 Language of Page: The language of the website is important. English is used consistently on all 5 pages of my website for understandable and readible purposes.

Guideline 3.1.5 Reading Level: In my process work page, the text requires reading ability more advanced than supplemental content, reading level is added so that users can get a simplified version of complex information.

Guideline 3.2.3 Consistent Navigation: This website includes the navigation bar, which is repeated on multiple web pages within a set of web pages occur in the same relative order each time they are repeated. I placed the navigation bar on each page on the top right corner to maintain consistent navigation without the users wondering where to go afterwards.

Robust

Guideline 4.1 Compatible: This website maximizes compatibility with current and future user agents, including assistive technologies.
